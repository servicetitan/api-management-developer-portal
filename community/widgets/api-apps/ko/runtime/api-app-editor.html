Client Credentials Management

To access ServiceTitan APIs, your app must authenticate itself by supplying a client ID and client secret. Who will be responsible for configuring these credentials within the app?
Select this option if, for example, you will manually enter the credentials into a file or database that can't be managed by tenants. After a tenant has connected your app, you can obtain the credentials by navigating to My Apps and clicking the View Connections button for the app.
Select this option if your app has a configuration screen where tenants can enter their own credentials. To obtain the credentials, tenants must sign in to the main ServiceTitan application and navigate to Settings > Integrations > API Application Access.
⚠
Security Note
You must keep client IDs and client secrets confidential. Never publish them with your source code, embed them within web pages, or distribute them via an app store.
